# Comandos de Terminal - Dia 02 
 
* `git config --global user.name` - Configura el nombre de usuario global en Git. 
* `git config --global user.email` - Configura el correo electronico global en Git. 
* `cat ~/.ssh/id_ed25519.pub` - Muestra la llave publica SSH creada en la terminal. 
* `md` o `mkdir` - Crea una nueva carpeta o directorio en el sistema. 
* `tree` - Muestra de forma grafica la estructura de carpetas en forma de arbol. 
* `echo` - Escribe texto en la terminal o crea archivos guardando lineas de texto. 
* `git init` - Inicializa un nuevo repositorio local de Git en la carpeta actual. 
* `git add` - Agrega archivos al area de preparacion (staging area) para el siguiente commit. 
* `git commit` - Registra los cambios guardados en el historial con un mensaje descriptivo. 
* `git remote add` - Vincula el repositorio local con un repositorio remoto en GitHub. 
* `git remote set-url` - Corrige o cambia la URL de un repositorio remoto ya vinculado. 
* `git remote -v` - Muestra los enlaces remotos actuales para verificar que esten bien escritos. 
* `git push` - Sube las confirmaciones locales al repositorio remoto en GitHub.
